# MCP logos

The catalog in `src/data/connectors.json` records the source URL for each bundled logo in `logoSource`. Assets are served locally so the directory does not depend on an external image service.

Brand vectors come from Simple Icons (via the existing react-icons dependency), SVGL, and Lobe Icons. Other images come from the project's published icon, provider favicon, ChatGPT directory artwork, or the brand's GitHub organization avatar. Each asset records its source; shared placeholder artwork is replaced with service branding. Logos identify the integrated service; the catalog's publisher and setup guide identify the actual MCP implementation, which may be community maintained.
